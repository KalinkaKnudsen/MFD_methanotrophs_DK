Supplementary Data File 1: S1_Table_1_methanotrophs_overview. Overview of the current status of methanotrophs in public databases.

Supplementary Data File 2: S2_methanotroph_IDs.tsv. Microflora Danica MAGs analysed here for methanotrophy. File includes ENA_ID and additional information on MAG quality, taxonomy and other key metrics.

Supplementary Data File 3: S3_GC_data_sorted_and_raw.xlsx. Gas chromatography data for the oxidation rate experiments. Found in the 'oxidate_rate_experiment' folder

Supplementary Data File 4: S4_Oxi_rate_mmlong2_bins.tsv. MAG statistics for oxidation rate experiments.

Supplementary Data File 5: S5_Protologue_table_methanotrophs.xlsx. Protologue table for proposed names for selected microbial lineages. 

Supplementary Data File 6: S6_GraftM_output.xlsx. Quantification of pmoA and mmoX sequences in the 10,683 Microflora Danica metagenomes and the three soils sequenced for oxidation rate experiments using pmoA and mmoX GraftM packages. Also available as separate files in GraftM_output.zip. 

Supplementary Data File 7 and 8 are found in the metadata folder

Supplementary Data File 9: S9_DRAM_tidy.tsv. Functional annotation of methanotrophs. DRAM functional annotation output for methanotrophs described in this study. A tidy version is uploaded, a full-version of the data is hosted at GitHub (Metabolism_DRAM.7z). 

Supplementary Data File 10: S10_KO_KSK_methanotroph_paper.xlsx. A list of KEGG Orthology (KO) identifiers used to perform functional annotation.
